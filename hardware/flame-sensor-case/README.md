# Grove Flame Sensor ケース（3D プリント）

Issue #3（遮光フード試作）で、Grove センサ基板を収めて満空灯に取り付けるために印刷しているケース。**第三者が公開しているモデルをそのまま取り込んだもの**で、本リポジトリのオリジナル設計ではない。

> **状態: 暫定。** 現在使っているモデルを記録として固定した段階。形状に不要な穴があるなど改善点があり、改良は今後の課題（下記）。

## 既知の課題（今後の改善）

- 余計な穴が空いている（用途に対して不要な開口）
- 遮光フードとしての外光遮断効果は、現場の状況（外光・設置面・満空灯の構造）に大きく左右されるため、一律の評価は行わない。設置ごとにケース・バイ・ケースで確認する（Issue #3 はこの方針でクローズ）
- 3 バリアントのうち、実際にどれを使っているかは未記載

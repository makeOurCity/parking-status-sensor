## Issue #2 チェック項目（暫定）

### 共通認識（全体）

- 満空表示は、写真から **発光式（LED）かつ色切替型** と判断
- パッチ（一辺 15〜25mm 程度）は、写真上の表示面に対して **貼付可能** と判断。厳密な寸法実測は PoC 段階では不要（設置時に問題が出たらその場で調整）
- LTE-M 強度・Wi-Fi 利用可否は、**これから確認**
- 設置許可は、**市役所分は見込みあり**。それ以外は施設所有者との相談が必要
- 電源は、写真上は給電点が見えないため **電池運用（LiPo）前提**で検討

### サイト別メモ

- 佐賀市役所（南・東）
  - 東の表示灯は南駐車場を指しており、2箇所の識別が必要
  - 1台マイコン + 2センサ構成の検討余地あり

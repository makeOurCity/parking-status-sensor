# Issue #88: リレー切り分け実験 記録シート

対象Issue: https://github.com/makeOurCity/parking-status-sensor/issues/88

> **方針変更（2026-10-07）:** ラッチングリレーは廃止し、ロードスイッチ基板（[88-load-switch-design.md](88-load-switch-design.md)）に置き換える。本シートの実験は、旧機体の不具合（#87）の原因を知るためのもので、**実施は任意**（廃止の判断には要らない）。原因の切り分けは未完のまま。再発時の記録（E2）だけは、旧機体が動いている間は役に立つ。

**種類: 作業記録ドキュメント（暫定・WIP）。** 実験の手順と、結果を書き込む欄をまとめたもの。実験の途中経過は、まず #88 の Issue コメントに書き、区切りができたらこのシートに反映して PR にする（AGENTS.md「ドキュメント運用」）。

## 目的

#87（2026-10-02）で、ラッチングリレーが約 9 時間（SET パルスを約 340 回送る間）切り替わらず、Grove ケーブルを差し直すと復活した。原因を切り分けて、次のどれかを決める。

- A. 接点・ケーブルの問題 → 堅牢化（はんだ付け、固定、コンデンサ追加）
- B. 5V 定格のリレーを 3.3V で駆動している余裕不足 → D8 短絡、駆動電圧の見直し、または別方式への置換
- C. コイル断線など個体の故障 → 交換

## まずやる最小セット（これだけで多くの仮説が切り分けられる）

実験は多く並べてあるが、**最初にやるのは次の 2 つだけ**。残りは、これらの結果で必要になったときだけ行う。

前提の確認: #87 のあと、このリレーは**現在また動いている**。つまり、コイルが開放している、といった「完全な故障」はすでに否定できる（開放なら今も動かない）。問題は「壊れたか」ではなく、「**一度切り替わらなくなった原因は何で、また起きるか**」。それを調べる実験に絞る。

1. **E3 の必須 2 構成**（各 20 回、約 15 分）: 3V3（実機相当）と、3V3 + ダイオード 1 個（約 2.6V）で SET の成功/失敗を数える。**電圧余裕の有無**が分かる。可能なら、故障が出た個体と別個体の両方で。
2. **E2**（次に再発したとき）: ケーブルに触る前の記録。実験ではなく、起きたときのメモ。何が効いて回復したかを分ける。

E1（テスターで D8 を確認）は、**余裕があれば**でよい。コイル抵抗の測定は、すでに動いている個体では情報が少ない（断続的なはんだ割れを静的な測定で拾える見込みは低い）。D8 が回路図どおり実装されているかの確認は、**同じ型の予備基板で足りる**。

回数が少なくてよい理由: #87 では 340 回連続で SET が失敗した。つまり問題は「確率的に時々失敗する」より「ある条件で失敗が続く状態になる」ことに近い。**条件が合えば 20 回でも全部失敗するか全部成功するか**に分かれるので、100 回や 1000 回で率を精密に出す必要はない。1 回でも失敗が混ざる構成があれば、それ自体が「余裕がない」という結果になる。

結果の見方: 3V3 で 20 回すべて成功し、ダイオード 1 個でも 20 回すべて成功なら、電圧余裕不足の可能性は下がる。ダイオード 1 個で失敗が出れば、余裕が薄いことが確認できる。

## E3. VCC を変えて SET/RESET の成功率を数える【最も情報量が大きい】

目的: この個体の「何 V・何 Ω で SET が落ちるか」を数値で出す。

### 電圧の作り方（可変のベンチ電源は不要）

リレーのコイルに掛かる電圧は、**VCC の電圧から、直列に入れた抵抗やダイオードの降下を引いたもの**になる。固定の電源 1〜3 種類と、部品で段階を作る。

| 作り方 | 実際の VCC（目安） | 備考 |
|---|---|---|
| XIAO の 5V ピン（USB 接続時） | 約 5V | 高い側の基準。**USB で給電している間だけ**。テスターで実測する |
| LiPo（Shield の BAT） | 約 3.7〜4.2V | 電池の残量で変わる。テスターで実測する |
| Shield の 3V3（実機と同じ） | 約 3.3V | 基準 |
| 3V3 + 1N4148 を直列 1 個 | 約 2.6V | ダイオードの降下は約 0.6〜0.7V |
| 3V3 + 1N4148 を直列 2 個 | 約 1.9V | 下限の確認用 |
| 3V3 + 直列抵抗 10 / 22 / 47Ω | 約 3.1 / 2.9 / 2.6V | コイル電流を約 15〜20mA として計算した目安（降下 = 電流 × 抵抗）。実際の値はテスターで測る |
| 3V3 + 可変抵抗（100Ω のトリマーなど）| 連続的に変えられる | 持っていれば、一番手軽に段階が作れる |
| 単 3 電池のホルダー（2 本 = 約 3.0V、3 本 = 約 4.5V） | 2 本 約 3.0V、3 本 約 4.5V | 安価。GND は XIAO と共通にする |

- **リレー基板のピンで、実際の電圧をテスターで測って記録する**。表の値は目安で、コイル電流や電池の状態で変わる。
- 直列抵抗・ダイオードの降下は、**コイルに電流が流れている間だけ**起きる。テスターで静的に測る電圧は、パルス中の電圧とは別（パルスは約 55ms で短い）。パルス中の電圧は E4 で測る。実験の基準は「どの構成で失敗が出たか」の記録で、電圧は目安として扱う。

### 配線

```
電源 +  ──┬── リレー VCC（Grove 赤）
          │      （E3-3 などでは途中に直列抵抗・ダイオードを入れる）
電源 −  ──┬── リレー GND（Grove 黒）
          ├── XIAO の GND
          └── 10kΩ の一端
XIAO D0 (GPIO1) ─── リレー SIG（Grove 黄）
3.3V ─── リレー 1COM
リレー 1NO ──┬── XIAO D2（ADC）
              └── 10kΩ ── GND
```

- 「電源」は上の表のどれか。実機と同じ 3V3 を基準にする場合は、Shield の 3V3 をそのまま使う。
- SIG は実機と同じ 3.3V ロジック。VCC が 3.3V 未満のとき、SIG のほうが VCC より高くなる。この条件の影響が入りうるので、結果にメモしておく。
- 1NO に 10kΩ のプルダウンを付け、**接点が閉じれば約 3.3V、開けば約 0V** になるようにする（実機の 0.77V の浮きを避けるため）。

### 試験用スケッチ（リポジトリには入れない。使い捨て）

```cpp
// リレー SET/RESET 成功率の計測。D0 = SIG、D2 = 1NO のセンス。
constexpr int kSigPin = D0;
constexpr int kSensePin = D2;
constexpr int kTrials = 20;

bool contactClosed() { return analogReadMilliVolts(kSensePin) > 2000; }

void setup() {
  Serial.begin(115200);
  pinMode(kSigPin, OUTPUT);
  digitalWrite(kSigPin, HIGH);  // RESET
  delay(1000);
  Serial.println("trial,dir,ok,mv");
}

void loop() {
  static int n = 0;
  if (n >= kTrials) { while (true) delay(1000); }
  ++n;
  digitalWrite(kSigPin, LOW);                       // SET（立ち下がり）
  delay(300);
  Serial.printf("%d,SET,%d,%u\n", n, contactClosed(), analogReadMilliVolts(kSensePin));
  delay(1000);                                      // SET と RESET の間隔は 150ms 以上
  digitalWrite(kSigPin, HIGH);                      // RESET（立ち上がり）
  delay(300);
  Serial.printf("%d,RESET,%d,%u\n", n, !contactClosed(), analogReadMilliVolts(kSensePin));
  delay(1000);
}
```

- `ok` は、SET のあとに接点が閉じていれば 1、RESET のあとに開いていれば 1。
- VCC を変えるたびにリセットして、`trial` を 1 から数え直す。

## 結果の読み方と次の行動

| 結果 | 結論（仮説） | 次の行動 |
|---|---|---|
| E1 でコイルが開放、または D8 が回路図と違う | コイル断線・はんだ割れ（H6）、または見積りの前提が違う | コイル開放なら基板を交換。D8 が違うなら、SET の電圧の見積りを見直す（#88 に記録） |
| E3 で 3V3 の SET 失敗が出る、または 3V3 + ダイオード 1 個（約 2.6V）で失敗が増える | 電圧余裕不足（H0） | D8 短絡の効果（E3-4）を確認し、D8 短絡 + コンデンサ追加を検討。改善しなければ、負荷スイッチへの置換を再検討 |
| E3-3 で 10〜47Ω の直列抵抗で SET が落ちる | 接触抵抗に弱い（H1 の引き金） | Grove ケーブルをやめる（はんだ付け・ネジ端子）、コンデンサ追加 |
| E4 のリレー側と Shield 側の VCC の差が 100mV 以上 | 接触が悪い（H1） | ケーブル・コネクタを交換、固定 |
| E2 で叩くと動く | 機械的な固着（H2） | E3 の電圧余裕と合わせて判断。個体交換 |
| E6 で VCC の差し直しだけで SET が出る | 差し直しが SET の刺激（機械的な衝撃ではない可能性） | 接触不良の可能性が残る。E4・E5 で確認 |
| すべて正常（E3 で失敗ゼロ） | 再現しない一過性の事象 | 現地での再発時に E2 を記録して追う。必要なら E4〜E6 を行う |

**この結果が出るまで、リレーの廃止・置換は決めない**（#88）。結果が「定格外駆動・機械固着」と確定し、かつ設置先が電池駆動の LTE-M を必須とする場合に、負荷スイッチへの置換を再検討する。

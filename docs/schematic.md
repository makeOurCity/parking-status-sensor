# 回路図（Wi-Fi 第1弾）

Issue #11。試作1台の電気回路。部品表は [bom.md](bom.md)、組み立て手順は [wiring.md](wiring.md)。

- **図面種別**: 単線図 / 複線図 / 回路図
- **対象**: XIAO ESP32S3 + TCS34725 + LiPo
- **対象外**: LTE-M（第2弾）、筐体（#12）
- **電圧**: DC 3.7 V（LiPo）→ 内蔵レギュレータ → DC 3.3 V 系統

---

## 図面記号・機器記号一覧

| 記号 | 機器 | 型番・備考 |
|---|---|---|
| BT1 | 二次電池（LiPo） | 3.7 V / 4,400 mAh、保護回路内蔵 |
| J1 | コネクタ | JST-PH 2.0（2極）、BAT 用 |
| J2 | コネクタ | 4P デュポン メス（延長ケーブル XIAO 側） |
| J3 | コネクタ | 4P デュポン メス（延長ケーブル センサ側） |
| J4 | コネクタ | 1×4 ピンヘッダ オス（センサパッチ） |
| U1 | マイコンモジュール | Seeed XIAO ESP32S3 |
| U2 | カラーセンサモジュール | TCS34725（I2C `0x29`） |
| C1 | 電解コンデンサ | 470 µF / 16 V |

端子名は XIAO・モジュール実装のラベルに合わせる。TCS34725 基板のピン物理順序は実物シルクで要確認（[wiring.md §3.3](wiring.md)）。

## 1. 単線図

系統と機能ブロックの関係。低圧 DC 電子機器としての単線表現。

```
                    ┌──────────────────────────────────────────┐
   情報系（論理）    │  [満空灯] → 光 → [U2 色検出]            │
                    │              ↑ I2C                      │
                    │         [U1 判定・MQTT]                  │
                    │              │ Wi-Fi                    │
                    │              ↓                          │
                    │         [クラウド / FIWARE]              │
                    └──────────────────────────────────────────┘

                    ┌──────────────────────────────────────────┐
   電力系（物理）    │                                          │
                    │   BT1 ──→ U1（電源・充電管理）            │
                    │              │                            │
                    │              ├── 3.3 V 系統 ──→ U2       │
                    │              │         └── C1            │
                    │              └── USB-C（充電・開発用）    │
                    └──────────────────────────────────────────┘
```

| 系統 | 電圧・媒体 | 経路 |
|---|---|---|
| 主電源 | DC 3.7 V | BT1 → J1 → U1（BAT） |
| 制御電源 | DC 3.3 V | U1 内蔵 LDO → 3V3 端子 → U2 |
| 通信（センサ） | I2C | U1 D4/D5 ↔ 延長ケーブル ↔ U2 |
| 通信（外部） | Wi-Fi 2.4 GHz | U1 内蔵アンテナ |

## 4. 端子台帳

### U1: XIAO ESP32S3（使用端子）

| 端子 | 内部 | 接続 | 線番 |
|---|---|---|---|
| BAT+ | 充電入力 + | J1-1 ← BT1 (+) | W1 |
| BAT− | 充電入力 − | J1-2 ← BT1 (−) | W2 |
| 3V3 | 3.3 V 出力 | C1 (+)、J2-1 | W3, W7 |
| GND | 共通 | C1 (−)、J2-2 | W4, W8 |
| D4 | GPIO5 / SDA | J2-3 | W5 |
| D5 | GPIO6 / SCL | J2-4 | W6 |

### U2: TCS34725 モジュール（使用端子）

| 端子（論理名） | 接続 | 線番 |
|---|---|---|
| VCC | J4-1 ← J3-1 | W3' |
| GND | J4-2 ← J3-2 | W4' |
| SDA | J4-3 ← J3-3 | W5' |
| SCL | J4-4 ← J3-4 | W6' |

### J2 / J3: 4P コネクタピン定義

| Pin | 信号 | 線色 |
|---|---|---|
| 1 | 3V3 | 赤 |
| 2 | GND | 黒 |
| 3 | SDA | 黄 |
| 4 | SCL | 緑 |

## 5. 電気的特性メモ

| 項目 | 値 |
|---|---|
| 主電源 | LiPo 3.7 V（満充電 4.2 V） |
| 制御電源 | 3.3 V（U1 内蔵レギュレータ） |
| U2 許容電源電圧 | 2.7〜3.6 V |
| I2C クロック | 標準モード 100 kHz 想定（ファームウェア設定） |
| 最大消費電流（目安） | Wi-Fi 送信ピーク 100〜180 mA 程度 |
